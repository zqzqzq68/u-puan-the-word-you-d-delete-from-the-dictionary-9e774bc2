The word this entry would erase from the dictionary forever: **queue**.

"queue" is pronounced "Q" — four of its five letters are silent. The joke lands the moment the word is gone, it comes entirely from the word's own spelling-versus-sound gap, and it is fresh: the field reaches first for "moist", for the longest words in the book, or for grammar-pedantry picks. "queue" is none of those, yet anyone who reads English gets it in one beat.

## Run it

```sh
python3 main.py
```

The program writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads it back to confirm the file holds exactly that word. No network, no clock, no randomness — two runs produce byte-identical output.
